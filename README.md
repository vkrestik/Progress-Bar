# Блок Progress для мобильных веб-приложений

Реализован переиспользуемый блок прогресса с круговой диаграммой для мобильных веб-приложений.

# Возможности

- **Normal** – отображает прогресс по числовому значению (0–100).  
- **Animated** – вращение круга для анимации.  
- **Hidden** – скрывает блок с экрана.  
- **API для управления** – легко использовать несколько экземпляров на странице.  
- **Адаптивный дизайн** – корректно отображается на разных устройствах и ориентациях.

# Использование

1. Введите число в поле **Value**, чтобы изменить прогресс.  
2. Переключатель **Animate** запускает или останавливает вращение.  
3. Переключатель **Hide** скрывает или показывает блок.
